TundraUX3 **V1.4**，相对上次正式发布 **v1.3**（2026-09-10）的更新如下。发布标签为 `v1.4`，工作区和安装包版本为 **1.4.0**。

本版重点是将 Linux 上整段以 root 运行的 UX，调整为真实系统用户会话，并提供可选的独立桌面会话与按需授权。**本次只发布 Linux x86_64 的 `.deb`、`.rpm` 安装包及校验文件**，不发布 Windows、macOS 或 Linux 便携包。

## 新增

- **真实 Linux 桌面会话**：新增 `tundra-sessiond`、可信 greeter 和完整 PAM 生命周期，包含认证、账户检查、凭据建立与会话打开，通过发行版的 `pam_systemd` 注册 logind。桌面与普通应用使用登录用户的 UID、主组和补充组，统一 NSS HOME、个人目录、XDG 配置/数据/缓存/状态目录、运行时目录和用户 D-Bus 环境。
- **按操作确认的系统授权**：新增常驻 root 的 `tundra-privileged`，通过 system D-Bus 接收有限的关机、重启、系统日志和官方更新请求。符合策略的本地管理员在独立可信界面查看具体操作并点击确认，无需为每项操作再次输入密码；默认选择取消。普通 UX 无法自行签发确认，接口不提供任意命令、任意路径或任意 UID 执行能力。
- **独立登录、锁屏、解锁和注销流程**：会话状态绑定真实 `UID + logind session ID`。锁屏保留用户进程，解锁重新认证同一用户并恢复原会话；注销先清理该会话进程，再关闭 PAM/logind 会话。同 UID 的其它独立 SSH 或桌面会话不会因注销被一并结束。
- **可信终端与设备移交**：安装包携带从固定源码构建、明确启用 libseat/logind 的私有 kmscon 及匹配模块，校验能力清单和文件摘要。可信 greeter 与用户终端分别使用独立 VT；锁屏时撤销用户对输入设备和 DRM master 的访问。读取线程、授权 worker 异常或设备移交失败会拒绝继续授权，不重放已确认操作。
- **独立 Logs 应用与结构化运行日志**：新增日志查询、筛选、事件与故障报告关联、只读诊断查看及 CLI 导出。日志记录 Explorer 操作、后台服务失败/恢复和 watchdog 事件，提供存储上限、隐私过滤和明确的权限检查。原仪表盘中的旧日志组件迁移至独立 Logs 入口，其它布局保留。
- **中英文 Fluent 语言资源**：新增统一的 `en-US` / `zh-CN` 消息资源、参数契约和不可变语言快照，覆盖主要界面、通知、诊断与恢复提示。语言切换在加载、校验、保存全部成功后生效；失败保留当前语言。默认资源损坏时自动修复，目录不可写时使用内置内存资源继续运行。
- **受保护维护与显式旧数据迁移**：新增包管理器拥有的稳定维护工具、版本化运行时、受保护更新信任根及事务恢复。离线迁移默认只预演，只有显式 `--apply` 才按目标系统 UID 写入；仅导入允许的偏好和内容，排除旧密码、角色、会话及启动命令，保留已有目标文件和原始来源。

## 修改与修复

- **Linux UX 不再要求 root，也不再自动调用 sudo**。普通终端直接运行 `tundra-shell` 即使用当前系统账户；以 root 启动会在初始化桌面前明确拒绝。旧应用配置中的用户名、密码和管理员标记不再构成 Linux 系统身份或授权依据。
- **系统更新从旧的 root 源码编译路径中拆分**：系统安装模式使用独立维护工具核验官方来源、证明、版本和摘要；应用更新前需完成注销与维护切换。版本切换保留恢复记录，修复更新日志创建前遗留维护标记的恢复行为。包管理器拥有的维护工具仍通过安装新版系统包更新。
- **收紧授权生命周期**：校验调用者真实 D-Bus 身份、进程、当前本地活动会话与管理员组；过期、取消、发送者退出或会话变化均不能继续执行。其它发送者即使是 root，也不能读取或取消原请求者的操作。关机/重启请求遵守 logind 阻止器。
- **修复锁屏后终端输入恢复、会话停止和 PAM worker 回收**：正常停止恢复原 VT，密码提示期间也可结束服务；旧会话进程清理完成后才返回登录界面。
- **完善 Linux 安装与 SELinux 标签**：版本化可执行文件和私有终端模块使用持久文件标签策略，保持 SELinux Enforcing；保留已有公共资源目录和本地自定义文件，安装策略后重新加载 D-Bus 配置。修复 Fedora CJK 字体依赖及 RPM 处理二进制导致摘要不一致的问题。
- **修复界面和资源细节**：补齐通知长内容滚动及可见操作按钮，统一翻译后布局与点击区域，修复首页图标资源键、Linux Btrfs 卷发现，以及语言/默认资源修复过程中覆盖健康自定义资源的问题。

## 行为与兼容边界

- **安装不会接管现有桌面**：独立会话服务需管理员主动启用。安装不会自动启动或启用座席服务、替换 SDDM 等显示管理器，或修改默认启动目标。软件包会创建专用 greeter 账户和 `tundra-admin` 组，但不会自动把任何真实用户加入该组。
- 默认点击授权要求用户显式加入 `tundra-admin`，并处于当前 Tundra 管理的本地活动会话；仅属于 sudo/wheel 组并不自动获得授权。SSH 或普通终端中运行 UX，不等于已经建立独立 Tundra 桌面；这类环境不会显示假锁屏，也不能获得托管桌面的系统操作确认。
- **切换用户先注销旧用户**，目前不保留多个并行用户桌面。初始独立后端面向 systemd/logind 的 `seat0`，使用可信 tty8 和用户 tty9，尚不是 Wayland compositor。启用前应按安装说明安排独占座席验证与恢复连接。
- Windows/macOS 代码保留普通 UX、个人文件和应用展示功能，不参与 PAM、logind、系统会话管理或底层提权。本次发布不提供这两个平台的安装制品。
- Fedora 构建与实机验证基线为 **Fedora 43 x86_64**；Debian/Ubuntu 安装包的构建基线为 **Ubuntu 24.04 amd64**。未将 Fedora 实机结论扩展为其它发行版的物理座席验证。
- 从旧版升级后请以普通用户运行 UX。旧 root 配置和内容不会自动迁移；需要时使用 `migrate-legacy` 指定经过检查的来源及目标系统 UID，先预演后应用。目标用户必须没有活动 logind 会话。
- 本次新增受保护在线更新框架，但**不发布在线更新 runtime envelope**。v1.4 请通过包管理器安装或升级；官方在线更新还依赖另行发布的可验证运行时制品和信任配置。完整官方在线更新成功路径、跨版本回滚，以及真实关机/重启未在本轮实机验证中执行。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.4-linux-amd64.deb` | Debian / Ubuntu amd64 |
| `TundraUX3-v1.4-linux-x86_64.sha256` | `.deb` 的 SHA-256 校验 |
| `TundraUX3-v1.4-fedora-x86_64.rpm` | Fedora 43 基线的 x86_64 RPM |
| `TundraUX3-v1.4-fedora-x86_64.sha256` | `.rpm` 的 SHA-256 校验 |

附带 `.sha256` 校验文件。下载后先运行 `sha256sum -c <校验文件名>.sha256`，再安装对应软件包：

```sh
sudo apt install ./TundraUX3-v1.4-linux-amd64.deb
# 或在 Fedora 上：
sudo dnf install ./TundraUX3-v1.4-fedora-x86_64.rpm
```

安装完成后，以普通用户运行：

```sh
tundra-shell
tundra-cli debug doctor
tundra-cli session status
```

独立座席服务的前置条件和启用步骤见 [Linux 安装说明](https://github.com/peixuanthomas/TundraUX3/blob/v1.4/packaging/linux/README-LINUX.txt)；迁移与维护流程见 [维护说明](https://github.com/peixuanthomas/TundraUX3/blob/v1.4/docs/linux/system-maintenance.md)。
