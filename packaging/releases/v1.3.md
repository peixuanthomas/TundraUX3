TundraUX3 **V1.3**，相对上次正式发布 **v1.2**（2026-09-07）的更新如下。发布标签为 `v1.3`，Cargo 工作区、内部 crate 和 Linux 安装包版本统一为 **1.3.0**。

## 新增

- **Fedora 系列 RPM 安装包**：新增 x86_64 `.rpm`，在 Fedora 43 环境原生编译并验证安装；包含 Shell、CLI、默认资源、桌面入口、许可证和适配 Fedora `system-auth` 的 PAM 配置。RPM 自动声明二进制库依赖，PAM 配置升级时保留本地修改。
- **Spring 界面风格与动画**：正式界面采用统一卡片间距、柔和入场效果，以及更新进度和系统用量条的阻尼弹簧动画；沿用主题、动画速度和减少动态效果设置，小窗口保留紧凑布局。
- **交互式 UI 风格预览**：新增 `tundra-cli debug view-ui-style [1|2|3]`，可对比 Glacier、Tea、Spring 三种风格，并体验列表、输入、弹窗和动画；预览不保存设置。
- **Editor C 语法高亮**：`.c` / `.h` 文件支持关键字、字符串、字符、数字、注释和预处理指令着色。默认文件关联扩充到 JSON、TOML、YAML、INI、XML、CSV 等文本格式；已有自定义关联保持不变。
- **系统状态概览与编辑体验**：独立 System Overview 展示 CPU、内存、存储、电池用量、网络和温度趋势、运行时间及主要进程；右键添加组件后进入编辑模式，并提供选中边框、编辑提示和减少动画适配。
- **更新过程实时反馈**：下载与编译过程显示持续进度和活动信息，便于判断长时间构建是否仍在运行。

## 修复

- **更新检查失败**：GitHub API 检查失败时可回退到 Git 获取更新信息。
- **Linux sudo 下找不到 Rust 工具链**：更新流程可查找调用用户已安装的默认 Rust 工具链，避免只依赖 root 的 PATH / rustup 环境。
- **源码更新占用临时内存文件系统**：将源码更新的编译工作放入磁盘缓存目录，避免在 `/tmp` 等内存临时目录中构建。
- **自更新覆盖本地资源**：更新仅替换 Shell、CLI 程序，保留默认主题、自定义主题和用户数据；使用协议 v2 的新更新助手，避免旧助手继续要求替换资源。旧协议更新记录会明确拒绝并保留原文件。
- **更新确认按钮文字被截断**：按钮宽度按完整标签计算。
- **Explorer 工具栏与键盘行为不一致**：补齐快捷键提示，恢复左右方向键后退/前进，统一刷新、排序、选项和回收站操作。
- **滚动条滑块不易分辨**：调整滑块与轨道的粗细，使滑块更清晰。
- **ANSI 终端强调色被改变**：保留用户配置的 ANSI 色相和普通/高亮选择，焦点色跟随强调色。

## 调整与兼容说明

- 移除 Launcher 的重新审批按钮和动作。
- System Status 右上角不再显示 Diagnostics / Logs / Incidents 按钮；仍可用 `H` / `L` / `I` 或仪表盘组件进入。
- Fedora RPM 的构建与安装验证基线为 **Fedora 43 x86_64**；其他 Fedora 衍生发行版需满足 RPM 声明的依赖。不将此包宣称为已验证的 RHEL / CentOS / Rocky / AlmaLinux 通用包。
- 程序内自更新仍从源码编译，需要本机 Rust 工具链；Linux 软件包管理器中的包版本需通过安装新版 `.deb` / `.rpm` 更新。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.3-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |
| `TundraUX3-v1.3-linux-amd64.deb` | Debian / Ubuntu amd64 |
| `TundraUX3-v1.3-fedora-x86_64.rpm` | Fedora 系列 x86_64（Fedora 43 构建） |

每个平台附带 `.sha256` 校验文件；下载对应安装包与校验文件后运行 `sha256sum -c <文件名>.sha256`（macOS 使用 `shasum -a 256 -c`）。

Fedora 安装：

```console
sudo dnf install ./TundraUX3-v1.3-fedora-x86_64.rpm
```

Debian / Ubuntu 安装：

```console
sudo apt install ./TundraUX3-v1.3-linux-amd64.deb
```

安装后从真实终端运行 `tundra-shell`，或用 `tundra-cli debug doctor` 检查运行环境。
