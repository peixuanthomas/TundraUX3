# ui

`screens/script/` 默认只显示源码与输出，变量、函数调用、表达式和断点按需打开；宽窗口显示可收起的右侧详情，窄窗口通过标签切换。操作栏按空闲、运行和调试暂停状态显示，复用 `PageActionBar`，最多五项。绘制、命中和终端尺寸共用同一布局，脚本断点和执行行仍按原始行号定位。

断点列表优先显示启用状态、行号和验证状态，调用栈优先显示函数名和行号，随后显示文件名，避免长目录遮住关键信息；定位源码后可查看完整路径。

编辑器缺少 Vim 引擎时显示居中的安装弹窗，复用共享进度条和取消按钮；下载百分比与解压、校验阶段分别显示。弹窗由 Shell 管理焦点和输入，支持键盘、鼠标及无悬停点按。

`ui` 把界面数据变成终端布局和画面，提供按钮、列表、输入、焦点、命中检查、主题和动画。它不管理终端模式，不执行系统操作，也不在绘制时修改应用状态。

内嵌终端按行合并同样式文字，字符宽度直接复用 Ratatui 的 `Span` 计算，避免每个终端格临时分配默认字符和 `Line`；命令行换行、原生终端裁切、宽字符占位和光标样式保持原有行为。

子终端图片通过 `TerminalImageFragment` 传递 RGBA、源裁切、内容区坐标、像素边距、子终端单元格尺寸及层级；`TerminalImageCache` 接收运行时合并的片段，先保留透明边距，再按实际视口裁切并缓存当前画面。Shell 为命令行、Vim 和脚本分别保存缓存，复用探测到的 Kitty、Sixel 或 iTerm2 输出。无原生图片能力、弹窗或布局过渡期间使用字符色块；透明、含像素边距或互相重叠的图片也使用半格合成，因为当前原生后端会清除覆盖区域的文字。该回退保留下层内容，但精细度低于原生图片。缓存预算在分配前检查。图片与文本、宽字符共同参与裁切，清屏和关闭页面时释放缓存及本程序创建的 Kitty 图片编号。

Launcher 的“运行设置 F4”复用 `ManagementForm`，提供系统启动或嵌入终端、参数与工作目录；Shell 管理输入和保存。外部终端页面显示应用名称，退出或启动失败的提示保留在底行，正文、图片、滚动条和鼠标命中共用扣除提示行后的区域。

共享输入模型保留 Kitty 特殊键、媒体键、修饰键、Press/Repeat/Release 阶段及数字键盘、Caps Lock、Num Lock 状态，子终端按协商结果编码。

屏幕键盘沿用 QWERTY 排列，宽窗口同时显示功能键、六键导航区与倒 T 形方向键；空间不足时由“功能区／字母区”按钮切换。`screens/screen_keyboard/keys.rs` 统一计算两种排列，绘制和点击共用按钮位置。

系统设置的“屏幕超时时间”复用共享选择弹窗，选中预设时长并确认后生效；文字来自中英文语言包。空闲计时与天气画面由 Shell 管理。

AA 设置通过选择弹窗提供“一律禁止／手动批准（默认）／一律放行”，选中和保存分别处理。

设置页最左侧大类由 Tab/Shift+Tab 切换；方向键只移动内容区焦点，上下键选择项目，左右键在应用列表与所选应用的设置之间切换。数值项在页面及高级动画弹窗中均显示为按钮，回车或点按打开同一个数值弹窗；弹窗复用 `TextInput`、共享按钮与布局，支持左右移动光标、直接输入、点按增减、确认和取消。

`automation::FrameCapture` 在外部控制开启时随实际绘制收集控件树。Shell 用 `begin` 开始一帧、`set_group` 标记页面与弹层及背景是否可操作、`finish` 读取最终 Buffer；它补充会话编号和任务、动画状态。控件 ID 由绘制层和已有组件 ID 组成，名称与显示文字随语言变化，位置使用终端字符格。列表行、表格单元格、按钮、输入框、滚动条、菜单和页面特殊控件都从本来的布局记录；未被控件包含的静态文字按可见行补齐。登录与设置向导的滚动画布沿同一个偏移转换位置。

快照保留焦点、选中、禁用、可操作和敏感状态。密码区域在控件、父容器和整屏文字中统一遮罩，包括登录页的“显示密码”、管理表单和 AA；屏幕实际绘制不受影响。外部子终端保留解析后的可见文字，中文的占位格不会导出成多余空格。图形协议的控制字节不进入快照；大字标题单独提供可读文字，图片仍通过所属控件的名称和区域表达。采集只描述画面，不执行业务动作。验证：`cargo test --locked -p ui --test automation`。

`PageActionBar` 共用 `ButtonEmphasis` 的主色、危险色和禁用样式，最多显示五个操作并在窄窗口换行，长按钮完整换行。绘制与点击共用操作编号和矩形。F1 帮助复用通知弹窗的布局、文本换行和滚动条，正文左对齐。用户管理的低频操作放在居中的“更多”菜单，设置底部只保留状态。

任务入口位于启动器；标题栏中的帮助与返回按钮之间留空，边框不连线。屏幕键盘展开时沿同一布局调整，不能覆盖页面或弹窗的提交、取消按钮。

| 位置 | 内容 |
| --- | --- |
| `src/foundation/` | 输入事件、焦点、命中检查与共享基础类型 |
| `src/components/` | 按钮、列表、表单、弹窗等通用控件 |
| `src/screens/` | 各页面的数据模型、布局与绘制 |
| `src/theme/` | 主题、颜色和控件状态样式 |
| `assets/` | 嵌入图标和时区地图，来源与许可见[资源说明](assets/README.md) |

页面只绘制 `ShellFrameLayout.main` 内的内容与页面弹层。Shell 最终绘制全局标题栏、状态栏、Toast 和模态弹窗。绘制和点击必须使用同一份布局。

`ScreenContent` 将弹层绘制分为下层与栈顶，供 Shell 在两者之间保留动画底图；`render_overlay` 仍可一次绘制全部弹层。数值弹窗下的高级选项保留原画面。

共享 `SidebarWorkspaceLayout` 提供大导航按钮、列表与详情分栏，`scrollable` 让分类较多的侧栏滚动并保持当前项可见；当前页通过 `Button::with_current` 持续强调并显示 `->`，不受鼠标或键盘焦点变化影响。列表选中条同样保留。窄内容区改为顶部导航和上下分栏。`WorkspaceFocus` 定义导航、搜索、列表、详情、操作和高级区域的焦点顺序，实际动作由 Shell 接入。

共享表格的选中行始终使用强调色；文件快速访问、时钟条目、启动器项目、日志当前分类和管理表单的已选值使用 `Button::with_current`，鼠标操作或切换区域后仍保留选中颜色。

`ManagementWorkspace` 将管理页操作分到导航、详情底部和默认收起的高级区域，布局与按钮命中共用操作编号。长按钮按当前字符宽度换行；详情容器沿共享 `Surface::focused` 显示键盘焦点。

管理工作区的高级入口可省略；没有高级操作时不绘制按钮、不预留区域，也不生成该区域的键盘焦点目标。

软件包展开详情时保留内容行，使用 Ratatui 双向滚动和共享滚动条查看被裁切的文字；滚动条按终端字符宽度计算，分别预留行列，避免覆盖内容。列表旁的详情预览继续换行显示。

`ManagementViewModel::selected_rows` 可单独传入全部选中行，空集合表示没有选中项；`selected` 继续表示当前位置。多选时所有已选行保持强调色，键盘当前位置另加下划线。软件包、服务、进程和计划任务的 Shift 操作与批量说明放在各自的中英文 F1 帮助中；页面不增加多选提示行。

共享 `ease_in_out_cruise` 按前 25% 时间加速、中间 50% 匀速、后 25% 减速计算位置，起止速度为零且分段速度连续；动画时钟、调度与 Shell 转场共用。`reveal_rect` 的 `Button(Rect)` 复用 animate 的矩形插值，让边框从入口按钮移动并放大到页面、弹窗或菜单的位置；`morph_surface` 保留边框样式与正常字号，逐步露出完整字符。`PanelMotion` 支持从当前位置反向开合，`expand_trailing_pane` 保持详情展开时逐步收拢列表，屏幕键盘也保留原来的底部开合。Shell 按真实输入来源决定是否播放，实体键盘及减少动态效果直接完成。

`MotionPhases` 接收三段时长并计算对应速度曲线，连接处速度连续。动画时钟和面板支持自定义阶段，默认曲线也使用相同计算。设置的动画百分比下方提供高级弹窗，内含九项毫秒设置，点按数值后通过数值弹窗确认。

共享库通过 `ui::animate` 导出 [animate 0.8.0](https://docs.rs/animate/0.8.0)，启用 `macros` 和 `ratatui`，可直接使用 `Tween`、`Spring`、`Clock` 与 `#[animate]`，支持 `Rect`、`Color`、`Style` 等 Ratatui 类型。使用宏时先 `use ui::animate`，再写 `#[animate::animate]`，也可以用 `#[ui::animate::animate(crate = ui::animate)]` 指定路径；可运行示例见 [src/lib.rs](src/lib.rs) 的导出文档。

`components::RainbowText::new(text, elapsed)` 是可直接绘制的 Ratatui 控件，复用 tachyonfx 的颜色转换，让彩虹颜色每三秒循环。按终端字符宽度着色，保留中文、组合字符、背景和字体样式。调用方传入实际经过时间，如 `MotionFrame::now`；彩虹持续播放，不受减少动态效果、动画速度或动画暂停影响。独立演示入口为 `tundra-cli debug test-rainbow-text`。

动画状态由调用方保存，使用本地 `Clock`，每帧传入 `MotionFrame::scaled_delta()`；同一帧只推进一次时钟，所有动画共用返回的时间。实体键盘操作或减少动态效果时调用动画的 `finish()` 直接到达目标，按 `Activity::running()` 决定是否继续请求下一帧。实际页面开合继续遵守统一 UI 要求中的方向、三段速度及绘制与点击位置一致的规则。

共享管理表单支持文件权限九宫格、混合值、勾选项及可查找选项列表。权限标题与格子共用列宽，按共享按钮的居中规则对齐；格子的绘制和鼠标/触摸命中共用布局。

设置侧栏把文件管理器与编辑器合并为“应用设置”，并在底部提供可点击、可用 F8 打开的“操作系统设置”入口。应用设置内使用左侧应用列表、右侧对应选项，当前应用保持强调色；列表和选项的绘制与点击共用布局。

Linux“区域与时间”复用时区地图弹窗，显示系统自动校时开关、服务器选择与逐项编辑、可点击的刷新入口；服务器表单沿用共享弹窗，文字区分系统服务器与演示模式的 HTTP 地址。

`ShellFrameLayout::with_input_keyboard` 按键盘动画进度收起普通页面的标题栏与底栏，并为内容留出可见空间；AA 保留背景布局，只移动自身弹窗。共享键盘入口按当前语言的文字宽度靠右放置，避免按钮文字截断。

所有控件遵守[统一 UI 要求](../../docs/UI-requirements.md)，具体页面合成见 [Shell 会话](../shell/docs/session.md)。通用交互要求只在规范中维护，避免各页面文档重复定义。

屏幕键盘会校正低对比度的普通字色；实际输入键盘把粘贴、收起作为最底排左右两端的普通按键，布局和点击区域一起随动画移动。文件侧栏分别显示当前位置与操作焦点。进程表优先显示名称、PID、CPU 和内存，日志列表显示本地时分秒并在详情保留完整时间；设置复用管理页侧栏，右侧直接显示设置卡片，底部仅保留状态。侧栏支持滚动并保持当前分类可见，窄窗口改用顶部导航。

管理页在窄窗口中优先保留搜索输入和光标，只显示能完整容纳的搜索、刷新按钮。

管理搜索在未输入时提示 `[/]` 进入，输入时提示 `[Enter]` 提交，普通页和分栏页共用文字；文件管理搜索入口也优先提示 `[/]`。

AA 输出区为共享滚动条预留一列，避免遮住文字或在出现历史输出时改变终端宽度；绘制和拖动命中使用同一布局。

文件管理器、编辑器、启动器、设置、系统状态与时钟表盘的外边框复用共享 `Surface`，形状与颜色跟随主题。编辑器菜单、正文与内部状态行均放在边框内，绘制与点击共用布局；窄窗口的数字时钟也为边框保留空间。

普通编辑器菜单栏提供 F8 Vim 开关。Vim 开启后，原菜单、正文和内部状态栏由原生 Vim 终端画面取代，只在右上角保留 F8“VIM模式已启用”按钮，普通编辑器显示“VIM模式未启用”；模式、待完成命令、Ex 命令行、查找、错误和状态行均由 Vim 自身显示。`editor_vim_terminal_area` 统一绘制、PTY 尺寸与鼠标坐标，终端快照保留斜体和原生光标形状。

共享 `Button::with_rainbow_label` 为已启用的 Vim 状态按钮提供持续播放的彩虹文字，悬停、按下和禁用时也继续变色，按钮边框、背景及交互状态沿用共享样式。原生终端参与实际画面的自动化采集。普通编辑器的 Vim 说明从帮助菜单打开，原生 Vim 帮助使用 `:help`。

文件管理的路径导航单独放在搜索框上方一行，路径按钮、地址编辑和点击区域共用同一布局。删除和清空回收站只使用 Shell 的全局确认框，页面不再绘制旧确认框。

文件管理器快捷访问与设置应用列表共用项高：正常高度下每项三行，文字后保留两行间距，较矮区域改用单行。整项均可点击，滚动容量按条目数计算，当前目录继续自动进入可见区域。

新建闹钟弹窗的取消按钮参与键盘焦点切换，并与可见按钮共用鼠标和触摸点击区域。

验证：`cargo test --locked -p ui`；交互变化还应验证键盘、鼠标/触摸命中及真实终端绘制。

固定测试保留共享控件交互、模态拦截、密码遮罩、宽字符和缩放后的可操作性。颜色和按钮状态集中在共享控件验证，页面不重复断言边框、固定文案和装饰细节。

`src/ui_test.rs` 将基础共享控件组合为六页演示，由 `tundra-cli debug ui-test` 启动。样例包含按钮状态、输入、列表、表格、导航、提示、弹窗和进度，数据仅保存在本次演示中。彩虹文本使用单独的 `debug test-rainbow-text` 演示。

动画高级选项使用居中弹窗，复用设置的数值入口、滚动条及恢复默认操作；其上打开数值弹窗时，只有最上层接收输入，关闭后恢复原选项。

输入弹窗的当前栏持续使用强调色，`TextInput` 只让插入光标闪烁；鼠标模式不隐藏输入位置。管理文字表单统一使用该控件，`TextEditState` 为已有字符串保存光标和选区。上下键切换栏目，左右键编辑当前栏，数值的增减保留可点击按钮。
