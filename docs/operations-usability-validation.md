# 2026-10-26 至 27 运维易用性验收

本轮面向不熟悉命令行的用户，补齐可见多选、内置文字输入、任务页、脚本界面、定时维护和配置备份管理。网络扩展、业务数据备份、远程主机列表和容器管理未纳入本轮。

## 备份规模测量

在 WSL debug 构建下创建临时旧记录，每条正文 32 KiB，每页 50 条。首次读取包括建立摘要索引，后续列表不读取正文、不计算全部差异。

| 记录数 | 首次重建索引 | 使用索引的首批读取 |
| --- | --- | --- |
| 100 | 116.7 ms | 1.94 ms |
| 1000 | 951.5 ms | 12.51 ms |
| 10000 | 9.43 s | 123.55 ms |

新记录从首次写入维护索引；旧记录首次建立索引仍需读取历史文件。10,000 条记录的清理请求小于 4 KiB，只传确认范围的固定摘要。清理时再次检查范围和文件版本；任一候选变化会拒绝旧确认。临时记录已删除。

复测入口：`cargo test --locked -p platform scale_measurement_100_1000_10000 --lib -- --ignored --nocapture`。

任务历史按来源手动清理。其他执行账户的记录保持只读；系统归档与个人副本分别确认、分别删除，不自动连带清理。自动批准审查拒绝了跨账户删除扩展和自动连带删除副本，本轮保留这些限制。

存储重开、旧进程身份和开机标记失配使用固定回归验证；没有实际整机重启或人为制造真实进程编号复用。分批暂存的零上下文补丁曾造成部分插入位置偏移，已通过独立修正提交校正；最终生产代码与通过测试的工作区一致。自动审查拒绝了重写分支历史的 `git reset --mixed master`，该操作没有执行。

用户已追加授权：全部实现和检查完成后，将 `work` 合并回 `master` 并推送远端；推送成功后删除本地 `work`。
