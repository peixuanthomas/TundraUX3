TundraUX3 **V1.3.2** includes improvements to Linux user and update management, Explorer file operations, and interface interactions since v1.3.1. The program version is standardized as **1.3.2**; this Linux release provides only a tar.gz portable package.

## Main updates

- The project's own code switches to GNU GPL v3; Weathr and other third-party code retain their original licenses.
- Linux uses the currently logged-in user's session and supports real system-account management. Startup asks for confirmation when running as root, and background listeners no longer remain running after exit.
- Linux updates are handled according to installation type: Fedora uses RPM and system authorization; Ubuntu and Arch support building and installing updates through the system package manager; portable builds are handled separately.
- Explorer supports multiple selection and C/X/V, D/Delete file operations, with improved selection states, default options, and document-opening behavior.
- Unified page rendering and transitions and added a top-right Back button. Fixed button responses to hovering, moving away after pressing, and releasing, as well as lingering keyboard-selection hints during mouse use.
- Fixed editor cursor visibility, repeated-key acceleration, scrolling at Unicode line endings, and terminal input issues.
- Added log-cleanup previews, restored macOS battery-status reading, and improved language and timezone setup on first Linux startup.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.3.2-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.2-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.2-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |

Three SHA-256 checksum files are included, for a total of six attachments. This release does not provide DEB or RPM packages.

```console
tar -xzf TundraUX3-v1.3.2-linux-x86_64.tar.gz
cd tundraux3-1.3.2-linux-x86_64
./tundra-shell
```

After extracting the portable package, run `./tundra-shell` from its directory, or use `./tundra-cli debug doctor` to check the environment. Keep the `assets` directory and installation-type marker file alongside the programs. Packages for all platforms include Chinese and English resources.

The release workflow runs workspace tests on Windows, macOS, and Ubuntu, builds three release packages, and checks the SHA-256 digests of all attachments before making the Release public. The macOS package contains both Intel and Apple Silicon architectures; it is neither developer-signed nor notarized by Apple.
