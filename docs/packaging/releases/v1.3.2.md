TundraUX3 **V1.3.2**，包含自 v1.3.1 以来的 Linux 用户与更新管理、Explorer 文件操作及界面交互改进。程序和 Linux 安装包版本统一为 **1.3.2**。

## 主要更新

- Linux 使用当前已登录用户的会话，支持真实系统账户管理；启动时确认 root 运行，并修复退出时后台监听未停止的问题。
- 按安装方式处理 Linux 更新：Fedora 使用 RPM 和系统授权，Ubuntu、Arch 支持构建并通过系统包管理器安装更新，便携版单独处理。
- Explorer 支持多选以及 C/X/V、D/Delete 文件操作，改进选择状态、默认选项和文档打开行为。
- 统一页面绘制及切换效果，增加右上角返回按钮；修复按钮悬停、按下后移出和释放时的响应，以及鼠标操作时残留的键盘选择提示。
- 修复编辑器光标可见性、连续按键加速、Unicode 行末滚动及终端输入问题。
- 增加日志清理预览，恢复 macOS 电池状态读取，完善 Linux 首次启动的语言和时区设置。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.3.2-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.2-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.2-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |
| `TundraUX3-v1.3.2-linux-amd64.deb` | Debian / Ubuntu amd64 |
| `TundraUX3-v1.3.2-fedora-x86_64.rpm` | Fedora x86_64（Fedora 43 构建） |

附带四份 SHA-256 校验文件，共九个附件。Linux 校验文件同时列出便携包和 DEB 包。

```console
sudo apt install ./TundraUX3-v1.3.2-linux-amd64.deb
sudo dnf install ./TundraUX3-v1.3.2-fedora-x86_64.rpm
```

根据发行版选择对应安装命令。安装后运行 `tundra-shell`，或使用 `tundra-cli debug doctor` 检查环境。便携包解压后从其中的目录运行 `./tundra-shell`。各平台包均包含中英文资源。

发布工作流在 Windows、macOS、Ubuntu 和 Fedora 执行工作区测试，构建五种发布包，验证 DEB/RPM 安装，并在公开 Release 前核对全部附件的 SHA-256 摘要。macOS 包包含 Intel 和 Apple Silicon 两种架构；未进行开发者签名或 Apple 公证。

**完整代码对比**：[v1.3.1...v1.3.2](https://github.com/peixuanthomas/TundraUX3/compare/v1.3.1...v1.3.2)。
