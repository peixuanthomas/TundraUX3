TundraUX3 **V1.3.3**，包含自 v1.3.2 以来的 Linux 系统管理、AutoAdmin 授权、便携版更新及终端交互改进。程序版本统一为 **1.3.3**。

## 主要更新

- **Linux 系统管理：**启动器新增服务、进程、软件包、网络和磁盘管理入口，可查看详情并执行受支持的操作。软件包支持 APT/dpkg 与 DNF，网络支持可识别的配置后端，磁盘支持挂载、卸载及空间扫描；可用功能取决于系统工具、服务和当前用户权限。
- **统一 AutoAdmin 授权：**系统管理及用户管理中的修改操作统一进入 AA，支持手动批准、自动批准和禁止模式。在内嵌终端查看实时输出、输入系统密码并回答安装问题；支持收起操作窗口及重新连接后台系统任务。
- **Linux 便携版更新：**设置中可选择正式版 Release 或 Beta；正式版下载稳定便携包，Beta 使用本机 Rust 工具链构建主分支。自更新保留个人数据与主题，并要求安装目录属于当前用户且可写。
- **命令行体验：**保留会话的环境变量和工作目录，提示符显示当前绝对路径，逐条呈现命令执行状态，并改进终端颜色与输入处理。
- **键盘、鼠标与触摸交互：**补充页面快捷键、可点击操作和提示，统一全局 Esc 返回、按钮焦点、悬停、按下与禁用样式；改进管理页搜索刷新、AA 窗口布局及确认按钮操作。
- **文件与编辑体验：**修复文件保存、复制与移动的安全及恢复问题，改进 Explorer 路径输入和文字选择，编辑器新增行号与已保存文本的修改标记。
- **状态与资源呈现：**系统状态支持通过列标题排序进程，优化进程指标配色；时钟支持编辑时间字段和点击箭头；恢复中文资源并简化资源恢复操作，修复鼠标输入影响天气动画节奏及 Windows 更新重启窗口的问题。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.3.3-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.3-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.3-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |

附带三份 SHA-256 校验文件，共六个附件。Linux 仅提供便携包，不提供 DEB 或 RPM 安装包。

```console
tar -xzf TundraUX3-v1.3.3-linux-x86_64.tar.gz
cd tundraux3-1.3.3-linux-x86_64
./tundra-shell
```

请同时保留 `tundra-shell`、`tundra-cli` 和 `assets` 目录；Linux 还需保留同目录中的 `tundra-installation.json`。各平台包均包含中英文资源。Linux 日常使用普通系统用户运行，需要额外权限时按界面提示完成授权。

Linux 是主要目标平台；Windows 和 macOS 主要用于体验界面与交互，不提供相同的 Linux 系统管理能力。macOS 包包含 Intel 和 Apple Silicon 两种架构，未进行开发者签名或 Apple 公证。
