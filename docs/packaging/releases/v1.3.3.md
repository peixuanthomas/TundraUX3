TundraUX3 **V1.3.3** includes improvements to Linux system management, AutoAdmin authorization, portable updates, and terminal interaction since v1.3.2. The program version is standardized as **1.3.3**.

## Main updates

- **Linux system management:** Launcher adds entry points for Services, Processes, Packages, Network, and Disks, with details and supported operations. Packages supports APT/dpkg and DNF; Network supports recognized configuration backends; Disks supports mounting, unmounting, and space scans. Available features depend on system tools, services, and the current user's permissions.
- **Unified AutoAdmin authorization:** modification operations in system and user management go through AA, with manual approval, automatic approval, and disallow modes. An embedded terminal shows live output and accepts system passwords and answers to installation prompts. The operation window can be collapsed, and background system tasks can be reconnected.
- **Linux portable updates:** Settings offers Release or Beta. Release downloads a stable portable package, while Beta builds the main branch using the local Rust toolchain. Self-updates preserve personal data and themes and require an installation directory that is owned by the current user and writable.
- **Command-line experience:** preserves the session's environment variables and working directory, shows the current absolute path in the prompt and each command's execution status, and improves terminal colors and input handling.
- **Keyboard, mouse, and touch interaction:** adds page shortcuts, clickable actions, and guidance, and unifies global Esc navigation back and button focus, hover, pressed, and disabled styles. Improves search refreshes on management pages, AA window layout, and confirmation-button operation.
- **Files and editing:** fixes safety and recovery issues in file saving, copying, and moving; improves Explorer path input and text selection; and adds editor line numbers and change markers relative to saved text.
- **Status and resource presentation:** System Status supports sorting processes by column headers and improves process metric colors. Clock supports editing time fields and clicking arrows. Chinese resources are restored, resource-recovery operations are simplified, and issues with mouse input affecting weather-animation timing and Windows update-restart windows are fixed.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.3.3-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.3-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.3-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |

Three SHA-256 checksum files are included, for a total of six attachments. Linux provides only a portable package, with no DEB or RPM packages.

```console
tar -xzf TundraUX3-v1.3.3-linux-x86_64.tar.gz
cd tundraux3-1.3.3-linux-x86_64
./tundra-shell
```

Keep `tundra-shell`, `tundra-cli`, and the `assets` directory together. On Linux, also keep `tundra-installation.json` in the same directory. Packages for all platforms include Chinese and English resources. For everyday Linux use, run as a normal system user and follow the interface prompts to authorize operations that need additional permissions.

Linux is the primary target platform. Windows and macOS are mainly for exploring the interface and interactions and do not provide the same Linux system-management capabilities. The macOS package contains both Intel and Apple Silicon architectures; it is neither developer-signed nor notarized by Apple.
