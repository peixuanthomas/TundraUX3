TundraUX3 **v1.3.1**，基于多语言开发完成后的版本，包含自 v1.3 以来的多语言、日志及资源恢复更新。程序、内部 crate 和 Linux 安装包版本统一为 **1.3.1**。

## 多语言与资源恢复

- 支持英文（en-US）和简体中文（zh-CN）Fluent 语言资源，覆盖 Shell、设置、通知、Explorer、诊断、启动恢复及 UI 风格预览。
- 统一语言目录与语言切换快照，保留用户语言配置；消息保留翻译键和参数，在显示时按当前语言呈现。
- 根据英文资源生成消息标识与参数约束，并检查语言资源完整性。
- 默认资源支持原子恢复及内存回退；修复自定义图片依赖缺失和首页图片图标资源键问题。
- 各平台发布包均包含英文和中文语言资源。

## 日志与问题修复

- 新增独立 Logs 应用、结构化运行日志、只读诊断查看及授权日志查询，关联 Explorer 操作、服务恢复和 watchdog 事件。
- 增加 Linux journal 与内核日志查询，对日志存储容量、关联信息及访问权限作边界处理。
- 修复 Linux Explorer 的 Btrfs 卷发现与 root 会话回收站生命周期问题。
- 修复长通知滚动、操作按钮可见性、语言选项点击区域及填充控件文字对比度。

## 版本范围

本版本以 `3cb92cdcdbe572920f588784194f3c6f34de3b37` 为功能基线。其后开发的 Linux 独立桌面会话、greeter、sessiond 和特权服务保留在 `linux-desktop-mode` 分支，不包含在本版本中。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.3.1-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.1-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.1-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |
| `TundraUX3-v1.3.1-linux-amd64.deb` | Debian / Ubuntu amd64 |
| `TundraUX3-v1.3.1-fedora-x86_64.rpm` | Fedora x86_64（Fedora 43 构建） |

附带四份 SHA-256 校验文件，共九个附件。下载对应安装包与校验文件后运行 `sha256sum -c <文件名>.sha256`（macOS 使用 `shasum -a 256 -c`）。Linux 校验文件同时列出便携包和 DEB 包。

```console
sudo apt install ./TundraUX3-v1.3.1-linux-amd64.deb
sudo dnf install ./TundraUX3-v1.3.1-fedora-x86_64.rpm
```

根据发行版选择上述安装命令之一。安装后从终端运行 `tundra-shell`，或运行 `tundra-cli debug doctor` 检查环境。Fedora RPM 的验证基线为 Fedora 43；程序内源码自更新仍需本机 Rust 工具链。

发布工作流在 Windows、macOS、Ubuntu 和 Fedora 执行工作区回归测试，构建五种发布包，验证 DEB/RPM 安装，并在公开 Release 前验证全部附件的 SHA-256 摘要。
