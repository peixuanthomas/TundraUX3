TundraUX3 **v1.3.1** is based on the version completed after multilingual development and includes multilingual, logging, and resource-recovery updates since v1.3. The program, internal crates, and Linux packages all use version **1.3.1**.

## Multilingual support and resource recovery

- Supports English (en-US) and Simplified Chinese (zh-CN) Fluent language resources, covering Shell, Settings, notifications, Explorer, diagnostics, startup recovery, and UI style previews.
- Unifies the language catalog and language-switch snapshots, preserving the user's language configuration. Messages retain translation keys and arguments and are rendered in the current language when displayed.
- Generates message identifiers and argument constraints from the English resources and checks language-resource completeness.
- Default resources support atomic recovery and in-memory fallback. Fixed missing custom-image dependencies and resource keys for image icons on Home.
- Release packages for all platforms include English and Chinese language resources.

## Logging and fixes

- Added a standalone Logs application, structured runtime logs, read-only diagnostic viewing, and authorized log queries, correlating Explorer operations, service recovery, and watchdog events.
- Added Linux journal and kernel log queries, with boundary handling for log storage capacity, correlation information, and access permissions.
- Fixed Btrfs volume discovery in Linux Explorer and the trash lifecycle in root sessions.
- Fixed long-notification scrolling, action-button visibility, click areas for language options, and text contrast in filled controls.

## Version scope

This version uses `3cb92cdcdbe572920f588784194f3c6f34de3b37` as its feature baseline. The standalone Linux desktop session, greeter, sessiond, and privileged services developed afterward remain on the `linux-desktop-mode` branch and are not included in this version.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.3.1-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.1-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.1-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |
| `TundraUX3-v1.3.1-linux-amd64.deb` | Debian / Ubuntu amd64 |
| `TundraUX3-v1.3.1-fedora-x86_64.rpm` | Fedora x86_64 (built on Fedora 43) |

Four SHA-256 checksum files are included, for a total of nine attachments. After downloading the appropriate package and checksum file, run `sha256sum -c <filename>.sha256` (use `shasum -a 256 -c` on macOS). The Linux checksum file lists both the portable and DEB packages.

```console
sudo apt install ./TundraUX3-v1.3.1-linux-amd64.deb
sudo dnf install ./TundraUX3-v1.3.1-fedora-x86_64.rpm
```

Choose one of the installation commands above for your distribution. After installation, run `tundra-shell` from a terminal, or run `tundra-cli debug doctor` to check the environment. The Fedora RPM validation baseline is Fedora 43; in-application source-based self-updates still require a local Rust toolchain.

The release workflow runs workspace regression tests on Windows, macOS, Ubuntu, and Fedora, builds five release packages, verifies DEB/RPM installation, and verifies the SHA-256 digests of all attachments before making the Release public.
