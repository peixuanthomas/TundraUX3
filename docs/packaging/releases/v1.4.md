# TundraUX3 V1.4

TundraUX3 **V1.4** 汇总自 v1.3.4 以来的系统管理、源码编辑器和交互改进。工作区各包版本统一为 **1.4.0**。

## 主要更新

- **Linux 系统设置：**“区域与时间”跟随系统时区，可从地图选择时区，并设置系统自动校时及 timesyncd/chrony 服务器；“操作系统设置”可管理主机名。本地文件日期也按系统时区显示。
- **文件权限与所有权：**可分别查看和修改文件、目录的权限及所有者；递归修改前显示会涉及的实际范围。
- **系统管理与恢复：**可查看监听端口，管理 UFW/firewalld 规则、SSH 设置和 systemd timer/cron 任务。SSH 修改会在新连接中验证；配置、网络和账户相关变更按组保存记录，可查看差异并恢复受支持的操作。
- **源码编辑器：**增加语法着色、正则查找与替换、多文档切换、软换行和 JSON 格式化；可保存 Vim 快捷键设置，并改进大文件处理。Explorer 默认将 106 种源码、配置和文本后缀交给编辑器，旧的未修改默认列表会自动升级，自定义列表保持不变。
- **命令行：**REPL 默认执行系统命令；TundraUX3 命令使用 `/` 前缀。补充命令和路径提示、目录补全及路径导航，改善 Windows Terminal → WSL 的组合键处理。
- **页面导航和动画：**设置、软件包及系统管理页面使用可滚动侧栏工作区。可单独调整页面、弹窗和菜单动画的加速、匀速及减速时间；鼠标和触摸打开页面时，边框从入口按钮展开，实体键盘切换仍即时完成。
- **屏幕键盘与操作提示：**管理表单和搜索共用屏幕键盘；列表选择、表单当前值及 Explorer 错误详情保持清楚可见。增加共享控件预览 `tundra-cli debug ui-test` 和彩虹文字演示 `tundra-cli debug test-rainbow-text`。
- **界面和稳定性修复：**改进软件包列表方向键、页面缩放、终端输入、鼠标点击、焦点恢复、Explorer 删除确认和行选择显示。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.4-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.4-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.4-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |

每个平台附带一份 SHA-256 校验文件，共六个附件。Linux 仅提供便携包，不提供 DEB 或 RPM 安装包。

```console
tar -xzf TundraUX3-v1.4-linux-x86_64.tar.gz
cd tundraux3-1.4.0-linux-x86_64
./tundra-shell
```

请同时保留 `tundra-shell`、`tundra-cli` 和 `assets` 目录；Linux 还需保留同目录中的 `tundra-installation.json`。各平台包均包含中英文资源。Linux 日常使用普通系统用户运行，需要额外权限时按界面提示完成授权。

Linux 是主要目标平台；Windows 和 macOS 主要用于体验界面与交互，不提供相同的 Linux 系统管理功能。macOS 包包含 Intel 和 Apple Silicon 两种架构，未进行开发者签名或 Apple 公证。

## 构建与发布

本版本由 GitHub Actions 的 `Publish V1.4 release` 工作流编译、打包并发布。工作流不运行测试套件；发布前核对版本和标签，上传后核对附件数量与 SHA-256。
