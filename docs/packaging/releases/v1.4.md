# TundraUX3 V1.4

TundraUX3 **V1.4** brings together system-management, source-editor, and interaction improvements since v1.3.4. All workspace packages use version **1.4.0**.

## Main updates

- **Linux system settings:** Region & Time follows the system timezone, supports selecting a timezone from a map, and configures automatic system time synchronization and timesyncd/chrony servers. Operating System Settings can manage the host name. Local file dates also use the system timezone.
- **File permissions and ownership:** file and directory permissions and owners can be viewed and modified separately. The actual scope of recursive changes is shown before applying them.
- **System management and recovery:** view listening ports and manage UFW/firewalld rules, SSH settings, and systemd timer/cron tasks. SSH changes are verified in a new connection. Configuration, network, and account changes are recorded in groups, with diffs and restoration of supported operations.
- **Source editor:** adds syntax highlighting, regular-expression search and replace, switching between multiple documents, soft wrap, and JSON formatting. Vim shortcut settings can be saved, and large-file handling is improved. Explorer opens 106 source, configuration, and text suffixes in the editor by default. Old, unmodified default lists are upgraded automatically; custom lists remain unchanged.
- **Command line:** REPL executes system commands by default; TundraUX3 commands use the `/` prefix. Added command and path suggestions, directory completion, and path navigation, and improved handling of key combinations from Windows Terminal to WSL.
- **Page navigation and animations:** Settings, Packages, and system-management pages use a scrollable sidebar workspace. Acceleration, constant-speed, and deceleration times can be adjusted separately for page, dialog, and menu animations. When a mouse or touchscreen opens a page, its border expands from the entry button; physical-keyboard switching remains immediate.
- **Screen keyboard and operation hints:** management forms and search share the screen keyboard. List selections, current form values, and Explorer error details remain clearly visible. Added the shared-control preview `tundra-cli debug ui-test` and rainbow-text demo `tundra-cli debug test-rainbow-text`.
- **Interface and stability fixes:** improved package-list arrow keys, page resizing, terminal input, mouse clicks, focus restoration, Explorer deletion confirmation, and row-selection display.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.4-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.4-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.4-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |

Each platform includes one SHA-256 checksum file, for a total of six attachments. Linux provides only a portable package, with no DEB or RPM packages.

```console
tar -xzf TundraUX3-v1.4-linux-x86_64.tar.gz
cd tundraux3-1.4.0-linux-x86_64
./tundra-shell
```

Keep `tundra-shell`, `tundra-cli`, and the `assets` directory together. On Linux, also keep `tundra-installation.json` in the same directory. Packages for all platforms include Chinese and English resources. For everyday Linux use, run as a normal system user and follow the interface prompts to authorize operations that need additional permissions.

Linux is the primary target platform. Windows and macOS are mainly for exploring the interface and interactions and do not provide the same Linux system-management features. The macOS package contains both Intel and Apple Silicon architectures; it is neither developer-signed nor notarized by Apple.

## Build and release

This version is compiled, packaged, and published by the `Publish V1.4 release` GitHub Actions workflow. The workflow does not run the test suite. Versions and tags are checked before release, and attachment counts and SHA-256 checksums are checked after upload.
