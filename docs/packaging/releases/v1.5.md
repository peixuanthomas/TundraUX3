# TundraUX3 V1.5

TundraUX3 **V1.5** 汇总自 v1.4.1 以来的跨平台软件包管理、脚本调试、任务操作和终端交互改进。工作区各包版本统一为 **1.5.0**。

## 主要更新

- **跨平台软件包管理：**macOS 可管理 Homebrew Formulae 和 Casks；Windows 可用 WinGet 搜索、安装、卸载和升级软件。
- **Linux 脚本调试：**Script Editor 提供 Bash 断点、单步执行、变量和表达式查看及交互输出。
- **真实 Vim 与内嵌终端：**编辑器支持完整 Vim；启动器可运行外部 TUI 应用，支持常见终端图像协议并清理应用进程。
- **任务与批量操作：**统一任务页面保留输出并支持取消；systemd timer、cron 和多选批量操作提供可见的表单与确认流程。
- **配置备份：**按页查看和筛选历史记录，清理前可预览将删除的范围。
- **启动器与界面控制：**可编辑自定义命令、图标和排序；`tundra-cli ui` 支持同一用户控制正在运行的界面。
- **性能与交互：**动画限制为 30 FPS，优化列表和终端渲染；统一表单、UX 日志和自适应屏幕键盘。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.5-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.5-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.5-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |

每个平台附带一份 SHA-256 校验文件，共六个附件。Linux 仅提供便携包，不提供 DEB 或 RPM 安装包。

```console
tar -xzf TundraUX3-v1.5-linux-x86_64.tar.gz
cd tundraux3-1.5.0-linux-x86_64
./tundra-shell
```

请同时保留 `tundra-shell`、`tundra-cli`、`assets` 和 `vim`；Linux 还需保留同目录中的 `tundra-installation.json`。各平台包均包含中英文资源。Linux 日常使用普通系统用户运行，需要额外权限时按界面提示完成授权。

Linux 是主要目标平台；Windows 和 macOS 主要用于体验界面与交互，不提供相同的 Linux 系统管理功能。macOS 包包含 Intel 和 Apple Silicon 两种架构，未进行开发者签名或 Apple 公证。

## 构建与发布

本版本由 GitHub Actions 的 `Publish V1.5 release` 工作流编译、打包并发布。工作流不运行测试套件；发布前核对版本和标签，上传后核对附件数量与 SHA-256。
