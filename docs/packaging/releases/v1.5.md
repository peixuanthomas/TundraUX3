# TundraUX3 V1.5

TundraUX3 **V1.5** brings together improvements to cross-platform package management, script debugging, task operations, and terminal interaction since v1.4.1. All workspace packages use version **1.5.0**.

## Main updates

- **Cross-platform package management:** macOS can manage Homebrew Formulae and Casks; Windows can use WinGet to search, install, remove, and upgrade software.
- **Linux script debugging:** Script Editor provides Bash breakpoints, stepping, variable and expression inspection, and interactive output.
- **Real Vim and embedded terminals:** the editor supports a full Vim instance. Launcher can run external TUI applications, supports common terminal image protocols, and cleans up application processes.
- **Tasks and batch operations:** the unified Tasks page preserves output and supports cancellation. systemd timers, cron, and batch operations on multiple selected items provide visible forms and confirmation flows.
- **Configuration backups:** browse and filter history by page, with a preview of the range to be deleted before cleanup.
- **Launcher and interface control:** custom commands, icons, and ordering can be edited. `tundra-cli ui` allows the same user to control the running interface.
- **Performance and interaction:** animations are capped at 30 FPS, list and terminal rendering is optimized, and forms, UX logs, and the adaptive screen keyboard are unified.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.5-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.5-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.5-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |

Each platform includes one SHA-256 checksum file, for a total of six attachments. Linux provides only a portable package, with no DEB or RPM packages.

```console
tar -xzf TundraUX3-v1.5-linux-x86_64.tar.gz
cd tundraux3-1.5.0-linux-x86_64
./tundra-shell
```

Keep `tundra-shell`, `tundra-cli`, `assets`, and `vim` together. On Linux, also keep `tundra-installation.json` in the same directory. Packages for all platforms include Chinese and English resources. For everyday Linux use, run as a normal system user and follow the interface prompts to authorize operations that need additional permissions.

Linux is the primary target platform. Windows and macOS are mainly for exploring the interface and interactions and do not provide the same Linux system-management features. The macOS package contains both Intel and Apple Silicon architectures; it is neither developer-signed nor notarized by Apple.

## Build and release

This version is compiled, packaged, and published by the `Publish V1.5 release` GitHub Actions workflow. macOS Vim is compiled separately on native ARM and Intel runners, then combined into a universal binary. The workflow does not run the test suite. Versions and tags are checked before release, and attachment counts and SHA-256 checksums are checked after upload.
