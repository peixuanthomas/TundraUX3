# TundraUX3 V1.5.1

TundraUX3 **V1.5.1** includes the improvements made on `master` since v1.5. All workspace packages use version **1.5.1**.

## Main updates

- **Home and Launcher:** edit and save the order of Home icons, use a compact layout in small terminals, and search Launcher without duplicating Home applications.
- **Files and editing:** share the file clipboard across pages, undo moves and renames within the same filesystem, browse destinations in the save picker, and use editor context actions without losing the selection.
- **Tasks and updates:** see task status in the title bar and toggle the task list. Source updates save complete build logs and reuse an installed Vim engine when its version is unchanged.
- **Interaction improvements:** management actions and selection controls are more visible, destructive confirmations default to cancel, and settings navigation and macOS text shortcuts are improved.
- **Fixes and documentation:** improve first setup, network status localization, firewall authorization, dashboard navigation, and logs. Linux defaults to ASCII icons, and the project documentation has been reorganized and translated into English.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.5.1-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.5.1-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.5.1-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |

Each platform includes a SHA-256 checksum file. Linux provides a portable package, with no DEB or RPM packages.

```console
tar -xzf TundraUX3-v1.5.1-linux-x86_64.tar.gz
cd tundraux3-1.5.1-linux-x86_64
./tundra-shell
```

Keep `tundra-shell`, `tundra-cli`, `assets`, and `vim` together. On Linux, also keep `tundra-installation.json` in the same directory. Packages include Chinese and English resources. The interface requires a terminal of at least 108 columns by 22 rows.

Linux is the primary target platform. Windows and macOS do not provide the same Linux system-management features. The macOS package contains Intel and Apple Silicon binaries; it is neither developer-signed nor notarized by Apple.

## Build and release

The `Publish V1.5.1 release` GitHub Actions workflow compiles, packages, and publishes this version. macOS Vim is compiled on native ARM and Intel runners and combined into a universal binary. The workflow does not run the test suite. It checks versions, tags, asset counts, and SHA-256 checksums.
