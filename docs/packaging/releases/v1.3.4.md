TundraUX3 **V1.3.4**，包含自 v1.3.3 以来的屏幕键盘、Linux 系统管理、AutoAdmin（AA）任务控制、命令行和文件处理改进。程序与工作区各包版本统一为 **1.3.4**。

## 主要更新

- **屏幕键盘：**运行中的 AA 弹窗和内嵌 Command Line 新增屏幕键盘入口，支持 QWERTY、Shift、Tab、CapsLock、方向键、常用组合键和剪贴板操作；展开时重新安排内容区域，优先保留 AA 窗口。增加实体按键亮起提示，改进按键颜色、动画和中英文说明。其他应用表单暂未接入，外部终端仍可通过 `tundra-cli debug screen-keyboard` 预览。
- **Arch Linux 软件包管理：**新增 pacman 已安装、搜索、详情、更新及修改操作；安装和升级会刷新仓库并升级完整系统，避免部分升级。不提供 AUR 构建或助手。补充软件源、配置文件冲突、包管理器状态及失败处理入口，恢复软件包列表与详情之间的导航。
- **系统配置编辑器：**在现有编辑器中打开受支持的系统配置，支持检查、授权保存、备份比较与恢复；同时检查外部文件变化。服务定义、软件源和自动挂载配置可通过此入口编辑，保存配置不会默认启动服务或立即挂载磁盘。
- **更多 Linux 管理操作：**服务增加配置、依赖和先后顺序查看、新服务及模板草稿；进程增加文件、端口、读写量和所属服务检查；磁盘增加健康、文件数量额度、自动挂载草稿及空间扫描定位。Wi-Fi 支持密码连接、结果验证和失败恢复，网络诊断提供分步结果。具体功能取决于系统工具、服务和权限。
- **完整账户管理：**用户管理移至启动器，补充账户按名查询、组、登录 Shell、SSH 公钥和有效期操作；远程账户只读，缺少 AccountsService 时由受支持的固定系统工具补足。所有修改仍需实际系统授权。
- **AA 授权与任务控制：**统一弹窗样式和动画；任务运行期间保留前台窗口，后台任务需要密码或确认时重新弹出。支持请求终止当前任务，等待超时后再次明确确认才强制停止；不会因自动批准而跳过系统认证或自动回答安装问题。加强本次 Shell 授权会话与提权任务的隔离，修复拒绝后不关闭及 sudo 退出后授权超时的问题。
- **正式运维 CLI：**补充服务、进程、软件包、网络、磁盘、账户、配置和任务命令，支持结构化结果、任务编号和明确的退出状态；完善设置、帮助、诊断和中英文操作流程。
- **命令行与文件管理：**REPL 默认执行系统命令，UX 命令使用 `/` 前缀；可从 Explorer 当前目录打开 Command Line。修复提示符颜色、间距和光标位置，补齐 Windows Terminal → WSL 的组合键输入。返回时确认并清理当前命令行的子进程，避免遗留后代进程；修复终端粘贴导致的崩溃，并提供更清楚的崩溃信息。
- **列表、导航与状态消息：**统一列表操作和可排序列标题，将常用管理操作放在右侧底部并显示真实快捷键。点击状态栏可阅读、滚动完整消息；修复用户管理返回位置、Explorer 点击外部关闭菜单和多选高亮，并让 Toast 遵循全局边框设置。
- **页面与后台任务：**各次打开的页面分别保存选择、表单和滚动位置；返回时恢复原页面。关闭有任务的页面可选择继续后台运行、取消后关闭或留在页面，旧任务结果不会写入重新打开的页面。统一弹窗顺序和输入焦点；更新准备支持取消，清理失败时保留错误和相关目录。
- **性能与维护：**子进程输出读取改为等待输出或退出通知；减少文件日志尾部读取中的分配，复用目录扫描信息并限制同时打开的目录。文档指纹改用带版本的 XXH3 格式，写入使用缓冲；增加可重复运行的性能检查及结果文档。拆分 AA 与终端运行代码，按功能整理模块和文档。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.3.4-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.3.4-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.3.4-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |

每个平台附带一份 SHA-256 校验文件，共六个附件。Linux 仅提供便携包，不提供 DEB 或 RPM 安装包。

```console
tar -xzf TundraUX3-v1.3.4-linux-x86_64.tar.gz
cd tundraux3-1.3.4-linux-x86_64
./tundra-shell
```

请同时保留 `tundra-shell`、`tundra-cli` 和 `assets` 目录；Linux 还需保留同目录中的 `tundra-installation.json`。各平台包均包含中英文资源。Linux 日常使用普通系统用户运行，需要额外权限时按界面提示完成授权。

Linux 是主要目标平台；Windows 和 macOS 主要用于体验界面与交互，不提供相同的 Linux 系统管理功能。macOS 包包含 Intel 和 Apple Silicon 两种架构，未进行开发者签名或 Apple 公证。
