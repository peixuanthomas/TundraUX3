# TundraUX3 V1.4.1

TundraUX3 **V1.4.1** brings together page help, action-button improvements, and interaction fixes since v1.4. All workspace packages use version **1.4.1**.

## Main updates

- **Help for the current page:** press F1 or click the title-bar Help button to view operations and shortcuts. Supports arrow keys, paging, the mouse wheel, and scrollbar dragging, and restores the previous focus on close. F1 in Command Line is still passed to the child terminal. Existing dialogs, AA, and the screen keyboard retain input priority.
- **Clearer action buttons:** common actions are placed consistently at the bottom of pages, with the primary action highlighted and destructive actions using the danger color. Each page shows at most five actions directly, and narrow windows and long button labels support wrapping. Persistent key instructions move into Help, while buttons retain their shortcuts.
- **Tools that are easier to find:** Explorer keeps the path, search, and refresh controls at the top and moves other tools into a menu. Launcher adds explicit actions and empty-list guidance. Logs, Diagnostics, and system management use consistent bottom actions. User management puts less frequent actions in a More menu, and Settings keeps status and errors at the bottom.
- **Explicit editing and cancellation:** System Status shows dashboard Edit, Save, and Cancel buttons. Clock highlights creation and confirmation actions. Read-only files can be reloaded through an editor button, and Home uses the danger color for signing out.
- **Interaction fixes:** fixed click targets after button wrapping, narrow-window layouts, and focus restoration after closing Help. Removed the extra border line between the title-bar Help and Back buttons.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX3-v1.4.1-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.4.1-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.4.1-linux-x86_64.tar.gz` | Linux x86_64 portable package (built on Ubuntu 24.04) |

Each platform includes one SHA-256 checksum file, for a total of six attachments. Linux provides only a portable package, with no DEB or RPM packages.

```console
tar -xzf TundraUX3-v1.4.1-linux-x86_64.tar.gz
cd tundraux3-1.4.1-linux-x86_64
./tundra-shell
```

Keep `tundra-shell`, `tundra-cli`, and the `assets` directory together. On Linux, also keep `tundra-installation.json` in the same directory. Packages for all platforms include Chinese and English resources. For everyday Linux use, run as a normal system user and follow the interface prompts to authorize operations that need additional permissions.

Linux is the primary target platform. Windows and macOS are mainly for exploring the interface and interactions and do not provide the same Linux system-management features. The macOS package contains both Intel and Apple Silicon architectures; it is neither developer-signed nor notarized by Apple.

## Build and release

This version is compiled, packaged, and published by the `Publish V1.4.1 release` GitHub Actions workflow. The workflow does not run the test suite. Versions and tags are checked before release, and attachment counts and SHA-256 checksums are checked after upload.
