# TundraUX3 V1.4.1

TundraUX3 **V1.4.1** 汇总自 v1.4 以来的页面帮助、操作按钮和交互修复。工作区各包版本统一为 **1.4.1**。

## 主要更新

- **本页帮助：**按 F1 或点击标题栏帮助按钮查看操作和快捷键，支持方向键、翻页、滚轮和拖动滚动条，关闭后回到原焦点。命令行中的 F1 仍交给子终端；已有弹窗、AA 和屏幕键盘优先接收输入。
- **更清楚的操作按钮：**常用操作统一放在页面底部，主操作突出显示，危险操作使用危险色；每页最多直接显示五项操作，窄窗口和长按钮文字可换行。常驻按键说明移入帮助，按钮保留快捷键。
- **更容易找到工具：**Explorer 顶部保留路径、搜索和刷新，其他工具收进菜单；启动器补充明确的操作与空列表提示；日志、诊断和系统管理统一底部操作，用户管理将低频操作收进“更多”菜单，设置底部保留状态和错误。
- **明确编辑与取消：**系统状态显示仪表盘编辑、保存和取消按钮；时钟突出创建和确认操作；只读文件可通过编辑器中的按钮重新加载，首页退出登录使用危险色。
- **交互修复：**修复按钮换行后的点击目标、窄窗口布局及帮助关闭后的焦点恢复，移除标题栏帮助与返回按钮之间多余的边框连线。

## 下载与安装

| 文件 | 平台 |
| --- | --- |
| `TundraUX3-v1.4.1-windows-x64.zip` | Windows x64 |
| `TundraUX3-v1.4.1-macos-universal.tar.gz` | macOS Intel + Apple Silicon Universal |
| `TundraUX3-v1.4.1-linux-x86_64.tar.gz` | Linux x86_64 便携包（Ubuntu 24.04 构建） |

每个平台附带一份 SHA-256 校验文件，共六个附件。Linux 仅提供便携包，不提供 DEB 或 RPM 安装包。

```console
tar -xzf TundraUX3-v1.4.1-linux-x86_64.tar.gz
cd tundraux3-1.4.1-linux-x86_64
./tundra-shell
```

请同时保留 `tundra-shell`、`tundra-cli` 和 `assets` 目录；Linux 还需保留同目录中的 `tundra-installation.json`。各平台包均包含中英文资源。Linux 日常使用普通系统用户运行，需要额外权限时按界面提示完成授权。

Linux 是主要目标平台；Windows 和 macOS 主要用于体验界面与交互，不提供相同的 Linux 系统管理功能。macOS 包包含 Intel 和 Apple Silicon 两种架构，未进行开发者签名或 Apple 公证。

## 构建与发布

本版本由 GitHub Actions 的 `Publish V1.4.1 release` 工作流编译、打包并发布。工作流不运行测试套件；发布前核对版本和标签，上传后核对附件数量与 SHA-256。
