# TundraUX3

**只用终端，也能直观地操作设备。**

[English](../README.md) | 简体中文

TundraUX3 希望让用户在没有图形桌面、只有终端的环境中，也能方便地操作设备。它把菜单、按钮、列表、表单和系统信息带到终端里，让常用功能更容易找到、操作，不必为每项任务记住命令。

项目有两个重点：**面向 Linux 的实用系统操作**，以及**键盘、鼠标、触摸屏三者都能独立使用**。每种输入方式都应能单独完成操作，让用户根据设备条件选择。

TundraUX3 使用 Rust 编写，基于 Ratatui 和 crossterm。目前仍在积极开发中，部分操作流程和系统功能尚未完成。

## 平台定位

| 平台 | 用途 |
| --- | --- |
| **Linux** | 主要目标平台，用于在只有终端的环境中操作设备和管理系统。 |
| **Windows** | 演示平台，用于体验界面和交互设计。 |
| **macOS** | 演示平台，用于体验界面和交互设计。 |

系统管理功能主要面向 Linux 开发。Windows 和 macOS 版本用于体验项目，不承诺提供同等的系统控制功能。Linux 上可用的操作取决于已安装的工具、正在运行的服务，以及当前用户的权限。

## 可以做什么

- **管理 Linux 设备：**查看和控制服务、进程，管理软件包，配置受支持的网络连接，查看磁盘和挂载点。
- **处理文件：**浏览目录、执行文件操作、编辑纯文本，也可以编辑 Markdown 源文。
- **打开工具：**通过应用启动器打开工具，需要命令时使用内置命令行。
- **了解系统运行情况：**查看系统状态、资源使用、日志、通知和诊断信息。
- **调整使用体验：**选择英文或简体中文、调整外观，以及使用时钟和天气应用。

具体支持的操作和所需条件见 [Linux 系统管理](linux-management.md)。

## 键盘、鼠标或触摸屏

三种输入方式均可独立使用，是项目的核心设计要求：

| 输入方式 | 预期体验 |
| --- | --- |
| **仅用键盘** | 使用按键和快捷键切换控件、选择操作、输入文字和切换页面。 |
| **仅用鼠标** | 通过可见的按钮、菜单、选择框和滚动条操作，不依赖键盘快捷键。 |
| **仅用触摸屏** | 通过点按控件和拖动滚动条操作，无需实体键盘或鼠标。 |

各页面的支持仍在完善。鼠标和触摸操作需要终端能够传递相应的指针事件。应用表单中的文字输入仍需要输入工具，例如实体键盘，或终端、系统提供的屏幕键盘。现在可以在外部终端通过 `tundra-cli debug screen-keyboard` 打开英文 QWERTY 屏幕键盘演示。键盘放在终端下半屏，按键宽度随终端宽度调整，包含数字、符号、F1–F12、Shift、Tab、CapsLock、Ctrl、Alt 和右 Ctrl。界面显示输入的文本和按键组合，并提供收起／展开、复制、粘贴、清空和退出按钮；复制会复制全部文本，粘贴会追加剪贴板内容。它尚未接入应用表单和内嵌 Command Line。因此，包含文字输入的完整纯鼠标或纯触屏操作，仍取决于所用环境。

点击底部状态栏的消息区域，可在弹窗中阅读完整文本。长消息会换行，并支持滚动；时钟仍保留独立的点击操作。

## 快速开始

请使用交互式终端，默认界面至少需要 **108 列 × 20 行**。内置命令行等应用需要更多垂直空间。鼠标和触摸支持取决于所用终端。

### 使用 Linux 便携包

1. 从 [GitHub Releases](https://github.com/peixuanthomas/TundraUX3/releases) 下载 Linux x86_64 便携压缩包。
2. 解压到属于当前普通 Linux 用户的目录。
3. 将 `tundra-shell`、`tundra-cli`、`assets/` 和 `tundra-installation.json` 保留在同一目录中。
4. 在解压目录打开终端并运行：

```sh
./tundra-shell
```

检查运行环境：

```sh
./tundra-cli debug doctor
```

Linux 版本使用启动程序的系统账户及其权限。日常使用普通用户运行；需要额外权限的操作，会通过相应的系统工具请求授权。退出 TundraUX3 会关闭应用并返回终端。

Linux 版本以便携包发布。在**设置 → 更新**中，**正式版（Release）**下载稳定的便携版本，**测试版（Beta）**使用本机 Rust 工具链编译 `master` 的最新提交。程序自更新要求便携目录属于当前用户且可写，并保留个人数据和主题。依赖与更新细节见 [Linux 运行说明](packaging/linux/README-LINUX.txt)。

### 从源码构建

安装当前稳定版 Rust 工具链、Cargo 和所用平台需要的构建工具。在仓库根目录执行：

```sh
cargo build --locked -p shell -p cli
cargo run --locked -p shell --bin tundra-shell
```

更新源码后也要依次执行这两条命令。单独运行 `cargo run -p shell` 不会重新构建 Command Line 使用的 `tundra-cli` 可执行文件。

查看配套命令行工具：

```sh
cargo run --locked -p cli --bin tundra-cli -- --help
cargo run --locked -p cli --bin tundra-cli -- debug doctor
```

请同时构建这两个包：Shell 的内置命令行和 Linux 管理任务会使用配套 CLI。构建、测试和打包细节见 [技术文档](README-TECHNICAL.md)。

## 当前限制

- 项目重点是终端界面。启动图形应用或调用桌面服务的功能，仍需要对应的应用或服务；在只有终端的会话中，这些功能可能不可用。
- Linux 管理功能各有运行条件，例如服务管理需要 systemd，软件包管理需要受支持的发行版工具。缺少组件时，界面会说明原因。
- 设置中的**声音、显示、Wi-Fi 和蓝牙**目前不可用。已支持的 Linux 网络操作由独立的“网络”应用提供。
- 各种输入方式的操作覆盖和真实设备上的表现仍在完善，项目尚不承诺支持所有终端、触摸屏或 Linux 发行版。
