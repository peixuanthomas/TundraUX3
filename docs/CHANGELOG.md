# 更新日志

本文件根据 Git 提交记录整理，按版本从新到旧排列。每个版本记录上一个版本标签之后、当前标签之内的主要变化；V1.0 包含最初开发阶段。相同功能的连续修复合并说明，合并提交、重复构建和仅调整测试的提交不逐项列出。

版本名称保留 Git 标签原有写法，日期采用标签所指提交的日期（UTC+8），不代表 GitHub Release 的实际发布时间。`archive/` 等归档标签不作为发布版本。旧版本条目描述当时的行为；当前使用方式见 [项目说明](README.zh-CN.md)。

## v1.3.3 — 2026-10-04

标签提交：`f2f5649`。[查看提交差异](https://github.com/peixuanthomas/TundraUX3/compare/v1.3.2...v1.3.3) · [发布说明](packaging/releases/v1.3.3.md)。

### 新增

- **Linux 系统管理：**新增服务、进程、软件包、网络和磁盘管理页面。软件包支持 APT/dpkg 与 DNF；提供受支持的服务控制、进程操作、网络配置、挂载、卸载和空间扫描，具体操作取决于系统工具与权限。
- **AutoAdmin 授权窗口：**统一系统管理和用户管理中的修改操作，提供手动批准、自动批准及禁止模式；内嵌终端显示实时输出，可输入密码并回答系统工具的问题。此版本支持收起任务窗口及重新连接任务。
- **Linux 正式版与测试版更新：**Release 下载稳定便携包，Beta 使用本机 Rust 工具链构建 `master` 指定提交；设置会保存所选模式。
- **编辑器改动标记：**显示行号，并与上次成功保存的文本比较，标出新增、修改和删除的行。
- **命令行会话：**保留系统命令的工作目录和已导出环境变量，提示符显示当前绝对路径，并逐条显示命令执行状态。
- **系统状态与时钟：**支持点击进程列标题排序，改进进程指标配色；时钟时间字段支持直接编辑和点击箭头调整。
- **键盘与触摸操作：**补充各页面快捷键、可点击控件及提示，增加 Linux 管理应用的主题图标。

### 调整

- Linux 自更新改为仅支持当前用户拥有且可写的便携安装，移除 PackageKit、APT、pacman 和 RPM 自更新路径；更新继续保留个人数据与主题。
- 统一页面的全局 Esc 返回，以及按钮焦点、悬停、按下和禁用状态的显示。
- 明确以只有终端的 Linux 设备操作为主要方向，增加中文 README；Windows 和 macOS 主要用于体验界面与交互。

### 修复

- 修复文件保存、复制、移动及失败恢复中的问题，改进 Explorer 路径追加输入和文字选择。
- 修复 Windows 自更新重启时提前交还终端的问题。
- 修复终端能力报告和 Escape 输入的处理，避免混入正常输入或误触发操作。
- 修复刷新事件打断退出按钮点击的问题，以及登录按钮 Enter 提示和命令行颜色问题。
- 修复 AutoAdmin 弹窗覆盖顶栏和状态栏、确认键连续触发后续输入的问题，完善按钮键盘操作；软件包安装直接显示 dpkg 的实时状态。
- 修复管理页面搜索未使用当前输入、中文资源恢复及 Windows 语言文件解码问题。
- 修复鼠标输入改变天气动画节奏的问题，简化资源恢复操作。

## v1.3.2 — 2026-09-27

标签提交：`581eef4`。[查看提交差异](https://github.com/peixuanthomas/TundraUX3/compare/v1.3.1...v1.3.2) · [发布说明](packaging/releases/v1.3.2.md)。

### 新增

- **真实 Linux 账户管理：**通过系统账户服务管理本地账户，支持资料、密码、角色、锁定及删除等操作；个人外观设置不依赖账户服务是否可用。
- **安装方式识别与更新：**区分便携安装和系统安装。当时的更新流程支持 Fedora 的 RPM/PackageKit 授权更新，以及 Ubuntu、Arch 的源码构建和包管理器安装更新；便携更新单独处理。
- **Explorer 多选：**补齐多文件选择，以及复制、剪切、粘贴和删除快捷操作。
- **导航与设置入口：**增加右上角返回按钮；增加系统设置界面框架，尚未接入可用的系统设置后端。
- **日志清理：**增加按范围清理调试日志及清理前预览。

### 调整

- **Linux 启动方式变更：**直接使用启动程序的系统账户，移除旧的应用内 Linux 登录流程；root 启动前需要确认，首次设置包含语言和时区。
- **许可证变更：**项目自身代码改用 `GPL-3.0-only`，Weathr 和其他第三方组件保留各自许可证。
- **Linux 发布包：**仅发布 tar.gz 便携包，不再提供 DEB/RPM 安装包；Windows x64、macOS Universal 和 Linux x86_64 各附校验文件。
- 由 Shell 统一绘制页面、标题栏、状态栏和弹窗，修正页面切换时的动画与遮挡关系。
- 统一按钮悬停与松开时触发的行为；首页和启动器要求在同一按钮上按下并于 500 毫秒内松开，鼠标操作时隐藏键盘选择标记。
- Weathr 锁屏可通过任意按键或点击进入；项目文档集中到 `docs/`。

### 修复

- 修复编辑器横向滚动越过 Unicode 行末、纵向移动时光标不可见及旧终端连续按键未加速的问题。
- 修复 Linux 普通文档仅因带有执行权限就被当成程序打开的问题。
- 修复 Windows 重启时新旧程序争用终端，以及发布构建显示调试信息的问题。
- 修复 Linux 退出时系统会话监听未停止、RPM 更新后重启不完整的问题。
- 恢复 macOS 电池采样，并保留读取失败信息。
- 修复命令行等待 Escape 序列时丢失后续输入，以及文件选项默认状态与焦点显示混淆的问题。

## v1.3.1 — 2026-09-12

### 新增

- **英文与简体中文：**引入统一语言资源，覆盖 Shell、设置、通知、Explorer、天气、诊断、启动恢复和界面风格预览；发布包包含两种语言资源。
- **独立 Logs 应用：**增加结构化运行日志、只读诊断查看、授权日志查询及命令行诊断，关联文件操作、服务恢复和 watchdog 故障事件。

- 修复 Linux Explorer 未发现 Btrfs 卷，以及 root 会话回收站处理问题。
- 修复长通知无法完整滚动、操作按钮被遮挡，以及语言选项点击区域不准确的问题。
- 修复实心控件中文字对比度、首页图片图标及自定义图片依赖缺失的问题。
- 修复日志关联信息、隐私过滤、存储上限和语言配置恢复中的问题。

## v1.3 — 2026-09-10

标签提交：`5ffdf72`；程序版本为 `1.3.0`。[查看提交差异](https://github.com/peixuanthomas/TundraUX3/compare/v1.2...v1.3) · [发布说明](packaging/releases/v1.3.md)。

### 新增

- **Spring 界面风格：**采用统一卡片间距、入场效果和进度动画，支持动画速度设置及减少动态效果。
- **交互式风格预览：**增加 `tundra-cli debug view-ui-style [1|2|3]`，可体验 Glacier、Tea、Spring 三种界面的控件与动画。
- **C 语法高亮：**编辑器为 `.c`、`.h` 文件提供语法着色，默认文本关联扩展到 JSON、TOML、YAML、INI、XML、CSV 等格式。
- **系统概览：**增加图形化系统概览，展示资源用量、趋势及主要进程，改进组件添加和编辑状态提示。
- **Fedora RPM：**新增 Fedora 系列 RPM 安装包及构建流程，当时与 Linux 便携包、DEB 包一同提供。

### 调整与修复

- **更新保留本地文件：**自更新只替换 Shell 和 CLI 程序，不再覆盖默认主题、自定义主题和用户数据。
- 更新下载及编译显示实时进度；GitHub API 检查失败时回退到 Git 获取信息。
- 修复 Linux sudo 环境找不到用户 Rust 工具链的问题，将源码编译移到磁盘缓存，避免占用内存临时目录。
- 修复 Explorer 工具栏快捷键与方向键导航、更新确认按钮文字截断、滚动条滑块不清晰的问题。
- 保留配置的 ANSI 强调色，移除 Launcher 的重新审批动作。

## v1.2 — 2026-09-07

标签提交：`ed30d64`。[查看提交差异](https://github.com/peixuanthomas/TundraUX3/compare/V1.1...v1.2)。

### 新增

- **System Status：**新增系统状态应用和原生平台数据采集，展示 CPU、内存、磁盘、网络、电池及进程等信息。
- **可配置仪表盘：**支持添加和编辑组件、调整大小、右键操作、键盘切换焦点及保存布局；增加历史趋势、活动详情和系统概览卡片。
- **Glacier UI 与动画：**统一页面控件，引入 Frost Motion 和 TachyonFX 动画，提供动画速度和减少动态效果设置。
- **程序自更新：**设置中增加更新检查、源码构建和更新记录；Windows、Linux 支持程序替换、启动检查、失败回退及中断恢复。
- **Linux 用户支持：**增加系统用户认证、个人目录识别和首次登录个性化设置，包括已有的本地化个人文件夹。
- **故障恢复界面：**增加全屏故障页，诊断命令统一归入 `debug`，故障测试可进入真实 Shell 恢复流程。
- **电源菜单：**增加电脑重启，并明确区分关闭应用、重启应用和系统电源操作。

### 调整

- **编辑器改为纯文本：**移除此前的富文档编辑方式，Markdown 按源文本编辑。
- 统一后台系统服务和数据刷新，集中处理终端能力检测；减少空闲轮询，限制采样与历史数据规模。
- Diagnostics、Logs 和故障记录重新组织到系统状态相关入口；Explorer 快速访问支持滚动与 Tab 切换。
- Launcher 改为检查目标是否存在，不再因程序内容指纹改变而要求重新确认。
- 内置 WezTerm 的实验实现移到独立开发分支，不包含在该版本主线中。

### 修复

- 修复图形图标探测、终端协议回退、图片尺寸计算及 WezTerm 中的图标显示。
- 修复弹窗进出动画、切页焦点闪烁、输入分发和点击区域不一致的问题。
- 修复系统状态刷新阻塞、失效数据、滚动和拖拽位置变化，以及不可用操作仍能触发的问题。
- 修复内嵌 Command Line 的 UTF-8 输出，完善 Explorer 和 Launcher 弹窗的键盘导航。
- 修复更新失败恢复路径、构建版本识别和更新历史滚动问题。
- 修正天气提供方及地点处理，并区分边框颜色和面板背景色。

## V1.0 — 2026-07-23

标签提交：`4fdb548`。[查看截至 V1.0 的提交](https://github.com/peixuanthomas/TundraUX3/commits/V1.0)。

### 首个版本

- **基础终端界面：**建立 Rust 工作区、Shell 事件处理、键盘鼠标输入、终端进入和退出恢复，以及首页应用入口；提供 Windows 与 macOS 平台适配。
- **首次设置与账户：**增加首次运行引导、锁屏登录、用户管理及个人外观设置，保存配置和应用状态。
- **Explorer：**提供跨平台文件浏览、鼠标操作、原生回收站、卷处理和可拖动滚动条。
- **Editor：**加入内置编辑器、文件打开方式，以及当时的富文档、标题和快捷编辑操作；支持在编辑器中查看日志文件。
- **Launcher：**增加应用固定、目标完整性检查、从 Explorer 添加应用及拖拽排序。
- **时钟与天气：**集成 Weathr，提供时区时钟、倒计时、闹钟和时间同步设置。
- **设置与主题：**支持配置边框形状、边框颜色、强调色、主题资源和用户外观，提供设置应用。
- **通知与故障处理：**增加全局通知中心、watchdog 故障监测、诊断中心和运行健康工具。
- **启动与退出：**加入启动动画、首次设置动画、退出确认和 Windows 关机选项；改进终端尺寸检查与返回天气界面的操作。
